# Hivion Lab — website

Landing page for **Hivion Lab**, an AI-native consultancy & automation studio.

- **Live site:** https://hivion.ai
- **Hosting:** GitHub Pages (static, no build step)
- **Live version:** `index.html` (a copy of the "Four Seasons" v5 concept)
- **Alternate design concepts:** `hivion-lab-website-v2.html` … `hivion-lab-website-v8.html`

## Editing

Everything is a single self-contained HTML file (inline CSS + JS, Google Fonts only).
To change the live site, edit `index.html`, commit, and push — GitHub Pages redeploys automatically.

If you change the live concept, replace `index.html` with a copy of the chosen version file.
